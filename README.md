В проекте были реализованы следующие задачи:
- Обработка создания записей клиента
- Механизмы авторизации и регистрации клиента
- Механизм отправки Записи клиента в основную базу

### Справочники
- [Услуги](#услуги)
- [Сотрудники](#сотрудники)

#### Услуги

| Реквизит            | Тип                        | Комментарий                |
|---------------------|----------------------------|----------------------------|
| Наименование | Стандартный реквизит, длина `100` символов | |
| Стоимость | `Число 15,0`, не отрицательное | Число указано с точностью 0, так как в мобильном приложении предполагается указывать цены в целых рублях |

#### Сотрудники

| Реквизит            | Тип                        | Комментарий                |
|---------------------|----------------------------|----------------------------|
| Наименование | Стандартный реквизит, длина `150` символов | ФИО сотрудника |

#### Пользователи

| Реквизит            | Тип                        | Комментарий                |
|---------------------|----------------------------|----------------------------|
| Код | Стандартный реквизит, длина `50` символов | Синоним GUID |
| Наименование | Стандартный реквизит, длина `100` символов | Синоним: `Имя пользователя` |

### Документы
- [Запись клиента](#запись-клиента)

#### Запись клиента

| Реквизит            | Тип                        | Комментарий                |
|---------------------|----------------------------|----------------------------|
| Сотрудник | [СправочникСсылка.Сотрудники](#сотрудники) | |
| __ТЧ Услуги__ |
| Услуга | [СправочникСсылка.Номенклатура](#номенклатура) | Обязательный для заполнения, Ограничение выбора: только типом номенклатуры `Услуга` |
| Цена | `Число (15,0)` | |

### Обработки
- [Регистрация записи клиента](#регистрация-записи-клиента)

#### Регистрация записи клиента

| Реквизит            | Тип                        | Комментарий                |
|---------------------|----------------------------|----------------------------|
| Дата записи | `Дата (дата и номер)` | |
| Сотрудник | [СправочникСсылка.Сотрудники](#сотрудники) | |
| Услуга | [СправочникСсылка.Услуги](#услуги) | Обязательный для заполнения |
| Стоимость | `Число (15,0)` | Заполняется из реквизита Цена справочника Услуги |
